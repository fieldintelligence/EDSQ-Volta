# MoM v2 validation — K2.5-judge lineup (2026-10-06)

First end-to-end validation of the "quality lane" mixture: K2.5 Tower
(native-INT4 GGUF from PMem DAX) as judge/aggregator over three fast
instant proposers.

## Validation result (1 question, streaming, 19m37s wall)

Question: 60/40 portfolio, E[r]=8%/3%, vol 12%/7%, ρ=0.2 → return + volatility.

- All three proposers returned plausible-but-wrong volatility (8.9 % / 9.2 %)
  — each mishandled the covariance term.
- The K2.5 judge flagged the disagreement, re-derived the formula, and its
  streamed answer walks the full covariance calculation (correct value
  8.2 %; expected return 6.0 % confirmed).
- Majority vote of the proposers alone would have been WRONG. The judge is
  the accuracy mechanism of this mixture.

## Operating envelope

- ~19-20 min per question in quality mode (judge thinking ON).
- Judge thinking OFF (chat_template_kwargs) projects to ~3-4 min per
  question but re-introduces majority-trust of wrong drafts — evaluate as
  "balanced mode" later.
- Fast lane (old all-instant stack, ~30-60 s/question at 0.83-0.85 battery)
  remains the latency lane; route per use case.
