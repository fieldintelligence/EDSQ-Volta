# Kimi K2.7-Code Q3 vs Q4 and Kimi K3 IQ2_XXS on the V100 pair (2026-10-08)

Same-session comparison on the two NVLink V100-SXM2 cards, tier-sharded
llama.cpp, identical flags and probes for every model. This closes backlog
item 2 ("K2.7-Code UD-Q3_K_XL downloaded — serve + compare vs Q4_K_XL").
Raw artifacts are in `kimi_k27_q3_vs_q4_k3_20261008/`.

own timings.

|---|---:|---:|---:|---:|---:|---:|
| warmup, 16 tok | 1.36 | 1.67 | 1.45 | 1.15 | 0.35 | 0.14 |
| 96 tok, cold | 4.81 | 2.76 | 4.70 | 1.34 | 0.46 | 0.16 |
| 96 tok, warm | 3.95 | 3.03 | 1.42 | 1.05 | 0.29 | 0.22 |
| word problem (104 / 104 / 186 tok) | 4.47 | 1.99 | 2.54 | 0.75 | 0.39 | 0.21 |
| code task (1215 / 942 tok) | 4.00 | **1.04** | 1.79 | **0.68** | not run | not run |

Correctness, checked by the probe: the word problem answer ("Answer: 42") is
right for all three models; the code task (a function plus three asserts,
executed) passes for Q3 and Q4.

## Reading

- **Q3 is faster than Q4 on every probe**: 1.5× on the long code task (1.04
  vs 0.68 tok/s) and 2 to 3× on the short ones. The earlier expectation that
  the CPU expert path is compute-bound, so a lighter quant would gain little,
  does not hold: the Q3 file fits the page cache entirely, while Q4 keeps four
  shards on PMem-DAX.
- The Q4 code-task rate reproduces the 2026-10-06 measurement exactly (0.68).
- **Quality on these two tasks is equal.** Two tasks cannot rank the quants;
  they only show that Q3 is not broken.
- Long outputs are slower than short ones for both quants (Q3 3.03 → 1.04).
- **K3 IQ2_XXS runs at 0.14 to 0.22 tok/s on the V100 pair**, about a fifth
  of K2.7 Q4, with 10 of 16 shards on PMem. It answers the word problem
  correctly in 20 minutes.

## Limits of this evidence

- One run per probe; no repeats, so no variance estimate.
- The K3 run is incomplete: it was stopped before the code task when a
  six-GPU K3 pilot started on the same host. That pilot is separate evidence.
- The 96-token probes are thinking-only output for K2.7 Q3-cold and for K3
  (zero visible characters); their rates are valid, their content is not a
  quality signal.
- Q3 and Q4 differ in tier placement as well as in quant, so the speed gap is
  the combined effect; this run does not separate the two.

## Role decision this supports

K2.7-Code Q3 replaces Q4 as the nightly code judge candidate: same answers on
the probes at 1.5× the rate, and no PMem tail. Before the Q4 files are
dropped, Q3 should pass the same judge set Q4 was accepted on. K3 IQ2_XXS on
two V100s is too slow for any scheduled role.
